────────────────────────────────────────────────────────────
LANGKAH 1 — Generate API Key
────────────────────────────────────────────────────────────

Jalankan perintah ini SEKALI untuk generate key rahasia:

    python3 -c "import secrets; print(secrets.token_hex(32))"

Contoh output:
    d77f0bfe85435adaf46dcab6fc2b6be21c8a5d9084fd0bcf57283b931012ed06

Simpan output ini — kamu akan pakai di dua tempat.

────────────────────────────────────────────────────────────
LANGKAH 2 — Tambah ke .env Flask
────────────────────────────────────────────────────────────

Buka file .env di folder python-forecasting/, tambahkan:

    FLASK_API_KEY=hasil_key_dari_langkah_1

────────────────────────────────────────────────────────────
LANGKAH 3 — Tambah ke .env Laravel
────────────────────────────────────────────────────────────

Buka file .env di root project Laravel, tambahkan:

    FLASK_API_KEY=hasil_key_dari_langkah_1

(nilai harus SAMA PERSIS dengan yang di .env Flask)

────────────────────────────────────────────────────────────
LANGKAH 7 — Test
────────────────────────────────────────────────────────────

Test 1: Pastikan health check masih bisa diakses (tanpa key = publik):
    curl http://127.0.0.1:5000/api/flask-health
    → Harus dapat response {"status": "online", ...}

Test 2: Pastikan endpoint dilindungi (tanpa key = ditolak):
    curl -X POST http://127.0.0.1:5000/api/forecast/predict-advanced \
         -H "Content-Type: application/json" \
         -d '{"commodity_id": 1}'
    → Harus dapat response 401 {"message": "Unauthorized: X-Flask-API-Key header missing."}

Test 3: Pastikan dengan key bisa diakses:
    curl -X POST http://127.0.0.1:5000/api/forecast/predict-advanced \
         -H "Content-Type: application/json" \
         -H "X-Flask-API-Key: HASIL_KEY_KAMU" \
         -d '{"commodity_id": 1}'
    → Harus dapat response prediksi normal

Test 4: Coba jalankan prediksi dari aplikasi web — harus berjalan normal.

────────────────────────────────────────────────────────────
CARA KERJA (ringkasan teknis)
────────────────────────────────────────────────────────────

Flask (app.py):
  - @before_request middleware memeriksa header X-Flask-API-Key
    sebelum setiap request masuk ke /api/*
  - Endpoint yang dikecualikan (publik): GET / dan GET /api/flask-health
  - Request tanpa key → 401 Unauthorized
  - Request dengan key salah → 401 Unauthorized
  - Key dibandingkan dengan hmac.compare_digest() untuk mencegah timing attack

Laravel:
  - AdminController, OperatorController, UserController:
    menggunakan method flaskHttp() yang otomatis menambahkan header
  - routes/api.php: menggunakan function flaskHttp() yang sama
  - Key dibaca dari env('FLASK_API_KEY') yang ada di .env Laravel
